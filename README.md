# Premier Coaching Website

Official website for **Premier Coaching**, providing quality coaching for students from Class 1st to 12th across CBSE, ICSE, and State Board in Dubagga, Lucknow.

## Technology Stack

- **React 19**
- **TypeScript**
- **Vite**
- **Tailwind CSS v4**
- **TanStack Start & Router**
- **Lucide Icons**
- **Sonner**

## Getting Started

### Local Development

Install project dependencies:

```bash
npm install
```

Start the local development server:

```bash
npm run dev
```

The application will start at [http://localhost:8080/](http://localhost:8080/).

### Production Build

Create an optimized production build:

```bash
npm run build
```

Preview the production build locally:

```bash
npm run preview
```

## Content Management

All website content, faculty details, course offerings, announcements, and contact information can be updated centrally in:

```
src/data/siteContent.ts
```

All local image assets and brand logo are organized in:

```
src/assets/
```
