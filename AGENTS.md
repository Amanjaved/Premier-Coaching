# Premier Coaching Website

An independent React, Vite, and Tailwind CSS website for Premier Coaching located in Dubagga, Lucknow.

## Development Guidelines

- **Centralized Content**: Update website copy, faculty details, courses, and announcements in `src/data/siteContent.ts`.
- **Assets**: Store real image assets in `src/assets/`.
- **Styling**: Tailwind CSS with custom theme tokens defined in `src/styles.css`.
- **Clean Architecture**: Preserve the modular component structure under `src/components/site/`.
